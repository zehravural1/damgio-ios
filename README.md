# Damgio — Dijital Damga Kartı

Damgio, kafe ve benzeri işletmeler için geliştirilen NFC/QR tabanlı dijital sadakat kartı uygulamasıdır.

## Proje Amacı

Kâğıt damga kartlarını dijital ortama taşıyarak müşterilerin damgalarını ve ödüllerini kolayca takip etmelerini sağlamak.

## Hedef Kullanıcılar

- **Customer:** Dijital kartlarını ve ödüllerini görüntüler.
- **Cashier:** Müşterilere damga ekler ve ödül kullanımını yönetir.
- **Admin:** İşletme ve sadakat programlarını yönetir.

## Planlanan Teknolojiler

- Swift
- SwiftUI
- Core Data veya SwiftData
- QR kod okuma
- Mümkün olması hâlinde NFC desteği
